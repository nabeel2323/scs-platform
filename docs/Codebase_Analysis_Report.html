5 · Advanced Improvements Beyond MVP

5.1 Performance

  • Eliminate N+1 in buildClaims via a single roles⋈permissions join; target <5 queries per refresh
  • Redis-cache categories/brands (60s TTL) — they front every search page
  • Single-flight refresh promise on web/admin clients
  • Adopt the live Socket.IO gateway for order-status push; retire polling
  • Enforce server-side pagination defaults (limit ≤ 50) on all list endpoints

5.2 Security

  • [P0] CORS: allow X-Device-Id
  • [P0] OTP verify: accept + persist deviceId; typed 401/429 exceptions
  • Extend @RequirePermission to merchant/catalog writes; seed merchant:* keys
  • Fail fast when JWT_ACCESS_SECRET unset outside development
  • Daily encrypted Postgres backup + restore drill (single P1 ops gap)
  • FCM notification on account lockout events
  • DTOs on all auth bodies so forbidNonWhitelisted actually filters

5.3 Developer Experience

  • CI: typecheck + lint + dart analyze + migration dry-run per PR
  • @scs/contracts: OpenAPI → TS + Dart codegen for all four clients
  • Coverage targets: 40% on identity/orders; widget tests for 4 auth screens; Playwright smoke for login/checkout
  • Seed: admin:* permission keys + demo password-credential user

5.4 User Experience

  • RFC 7807-aware localized error surfaces on all clients
  • "Forgot password" → OTP-reset flow (OTP remains authoritative)
  • Remaining-attempts UX on lockout (read X-RateLimit-Remaining)
  • Mobile offline cart queue via the existing drift dependency
  • Skeleton loaders on web (mobile already has shimmer)

5.5 Scalability

  • Stay modular monolith through pilot; first extraction candidate: notifications (already isolated)
  • BullMQ import worker on existing Redis — unlocks real CSV parsing
  • Read replicas only after Phase 3 volume; measure buildClaims first
  • Enforce documented module-boundary lint rules
