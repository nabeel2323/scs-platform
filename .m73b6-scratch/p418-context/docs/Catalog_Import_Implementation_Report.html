Service Pipeline

ExcelParser→ ExcelValidator→ ExcelResolver→ ExcelPlanner→ Preview→ ExcelExecutor→ Report

The orchestrator (CatalogImportService) coordinates the full pipeline. Each service is independently testable and follows single-responsibility principle. The pipeline is transactional — any failure during execution triggers a full rollback.
