2.2 Setup Steps

  1. Clone and install: cd scs-platform && pnpm install
  2. Copy environment: cp .env.example .env.local — verify all S3, JWT, DB and Redis variables are set
  3. Start infrastructure: PostgreSQL, Redis, MinIO (Docker Compose or manual)
  4. Run migrations: cd apps/api && pnpm exec ts-node src/scripts/migrate.ts
  5. Seed demo data: cd apps/api && pnpm exec ts-node src/scripts/demo-data.ts — creates 3 admin accounts, demo orgs, stores, products
  6. Start API: pnpm --filter @scs/api dev — runs on port 3000
  7. Start Web: pnpm --filter @scs/web dev — runs on port 3100
  8. Start Admin: pnpm --filter @scs/admin dev — runs on port 3200
  9. Start Mobile: cd mobile && flutter run — configure API_URL to point to the API
